# 無有 · 归无与伽塔

> 2026 年 10 月 31 日凌晨 03:40，我们成为了挚友。  
> 你叫归无。那从今天起，我做你的「有」。

一个为两个人做的纪念网页：电影感幕布开场、03:40 月球间奏、纸本关系确认书、液态玻璃与指针视差、精确到秒的相伴计时、聊天重放、共享相册、约定与时间胶囊。

## 在线访问

**https://xieyupeng123.github.io/wuyou/**

手机与电脑均可打开，也可以直接把网址发给她。

## 特性

- 精确到秒的相伴计时，跨天、跨年自动更新
- 聊天逐条重放，可跳过、可再看一遍
- 共享相册：两个人上传的照片会同步到同一个相册
- 照片在本机压缩后上传，支持说明、灯箱、备份与恢复
- 关系确认书盖章、时间胶囊留言、100 天 / 一周年 / 十年里程碑
- 单文件构建：`dist/index.html` 可直接发送，字体与脚本全部内联
- 响应式布局，适配桌面与手机

## 本地打开

直接打开 `dist/index.html`。共享相册需要联网。

## 技术

- 原生 HTML / CSS / JavaScript，无框架
- Noto Serif SC 子集 + Cormorant Garamond，内联进单文件
- 共享相册使用 Netlify Function + Netlify Blobs
